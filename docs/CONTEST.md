# 공모전 기준과 구현

공식 [지원·제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission)에 맞춰 소스, `apk/`의 서명된 release APK, 앱 이름·한 줄 소개·실행 방법·테스트 환경·다운로드 위치를 제공한다. README와 Releases에서 시연용 APK도 함께 받을 수 있다.

## 평가 항목에 대한 설명

항목은 [공식 심사 안내](https://appdevchallenge.auto-hmg.io/guide/judging-awards)에 따른다. 아래 내용은 프로젝트의 설명이다.

| 항목 | 원정 보스의 구성 |
|---|---|
| 차량특화성 | Vehicle SDK 누적거리 차이를 주차 후 필살기로 전환하고, 기어·화면 제한·전면 상태로 게임 실행을 제어 |
| 창의성 | 일상의 이동을 다음 보스전으로 이어지는 수집 목표로 연결. 상자·장비·도감과 친구 교환으로 육성 선택을 확장 |
| 기술 활용성 | Vehicle 2.3.2의 지원 확인·거리 조회, NaviHelper 안내 조회, AAOS 읽기 API, Room의 정산·거리·상자 동시 저장과 교환 트랜잭션 |
| 사업성 | 짧은 육성·수집을 즐기는 순정 내비 사용자를 초기 대상으로 설정. 상점 선택·친구 교환·시즌 수집으로 반복 이용을 유도하는 가설 |

상점은 게임 코인으로만 이용한다. 광고·유료 상자·현금 결제는 없다. MAU·잔존율·매출을 실측한 것처럼 제시하지 않으며 시연 사용자 반응과 재방문을 통해 사업 가설을 검증한다.

## 주차 후 조작

상자 개봉, 장착·강화, 상점 구매·판매, 친구·교환 화면과 자동 전투는 P 기어·`CarUxRestrictions`·앱 전면 상태를 확인한다. 주행 중에는 전투 실행을 중단하며, 복귀 시 최대 8시간의 기본 성장과 최대 30km의 거리 필살기를 한 번 정산한다. 주행 속도로 피해량을 높이지 않는다. 거리값이 없어도 기본 사냥은 가능하며, 주차 상태를 확인할 수 없으면 화면과 전투를 중단한다. 이 설계가 심사 통과나 앱 마켓 승인을 의미하지는 않는다.
