# 0.5.0 차량 화면과 작은 픽셀 전투 패널

검증일 2026-11-15. `versionName=0.5.0`, `versionCode=5`.

## 구현

- 차량 상태·복귀 거리·필살기 피해·성장 보상을 중심에 두고 전투는 작은 세로 패널로 표시한다.
- 픽셀 보스는 위, 캐릭터는 아래에 고정한다. 검의 에너지파·망치의 파동·창의 관통탄·지팡이의 마법탄만 이동한다.
- 실제 장착 무기·방어구·장신구와 강화 +3/+5 효과를 전투와 장착 미리보기에 반영한다.
- 기본 작은 패널과 확대 패널을 전환한다. 넓은 창·Pleos 1:1 분할 창에서 게임과 차량 보상 정보를 함께 표시한다. 더 좁은 창에서는 전투 패널을 먼저 배치한다.
- `resizeableActivity=true`를 선언한다. 새 오버레이 권한이나 다른 앱 위에 띄우는 창은 추가하지 않는다.

공식 [창 정책](https://document.pleos.ai/docs/connect/guide/docs-design/getting-started/window)에 따라 Pleos가 관리하는 앱 창을 사용한다. [실제 분할 창 캡처](../../artifacts/screenshots/pixel-vehicle-split.png)의 왼쪽은 시스템 차량 영역, 가운데는 게임 앱, 오른쪽은 순정 내비 앱이다. 순정 내비 지도에 게임을 덧그린 화면이 아니다. 에뮬레이터 내비의 지도 타일은 표시되지 않은 상태다.

## 이번 버전의 확인 결과

| 확인 항목 | 결과 |
|---|---|
| 화면·복귀·주행 차단·장착·패널 크기 전환 | `FixtureJourneyUiTest` 5개 통과 |
| 상점 구매 확인·재화 차감·친구 화면 진입 | `CommerceUiTest` 1개 통과 |
| 작은 패널 크기 변경 | 실제 너비 변화와 장착 데이터 불변을 자동 검사 |
| Pleos 창 크기 | 시스템 창 바를 드래그해 넓은 창 ↔ 분할 창을 실제 실행·촬영 |
| 게임 규칙 | 변경 없는 기존 단위 37개 결과를 빌드에서 재사용 |
| fixture/SDK debug·서명 release | 빌드 성공, release APK v2 서명 확인 |
| release lint | 오류 0개, 경고 18개. 기존 API·개발 도구 관련 권고 포함 |
| SDK 빌드 실행 | Vehicle SDK 2.3.2 누적거리 0m, AAOS 주차 허용, NaviHelper 연결을 실제 수신 |
| 실제 기능 조작 | 지팡이 장착·+1→+3 강화, 상자 개봉, 45코인 구매, 두 시연 계정의 교환 수락·완료 촬영 |

이번에 실행한 기기 테스트는 **6개**다. [화면 테스트](instrumentation-ui.txt), [상점 테스트](instrumentation-commerce.txt), [lint](lint-0.5.txt), [SDK 수신 상태](sdk-visual-0.5.json)를 제공한다. 저장·서버·거리 정산 규칙은 변경하지 않았으며 해당 이전 검증 범위는 [0.4.0 기록](UPGRADE_0_4.md)에 있다.

주행이나 앱 이탈 시 전투 루프와 게임 화면을 중단하는 기존 동작을 유지한다. 주차 후 복귀하면 최대 8시간 기본 결과와 확인된 거리의 필살기를 한 번 계산한다. 이번 변경은 전투 규칙·보상량·실시간 주행 게임을 추가한 것이 아니다.

## 시연 범위

90초 영상은 전부 0.5.0 앱의 녹화와 테스트 캡처로 갱신했다. 차량 전체 화면에서 시작하고, 기능별 확대·정지 편집으로 결과를 읽히게 한다. 음성·효과음은 없다. 가상 7분·10km 입력과 실제 SDK 누적거리 0km 수신은 구분한다. [영상 구성](../DEMO_VIDEO.md)과 [파일 정보](../demo/video-manifest.json)를 참고한다.

환경: 공식 Pleos Connect Emulator 2.1.0, API 34, x86_64, 2560×1440, 160dpi, RAM 4GB, SwiftShader. 공개 운영 서버는 제공하지 않으며 친구·교환은 포함된 PC 서버로 시연했다.
