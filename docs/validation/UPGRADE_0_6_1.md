# 0.6.1 차량 시나리오와 주차 화면 안정화

## 수정한 문제

실제 SDK의 새 주차 상태가 500ms 간격의 화면 시계보다 나중에 도착하면, 두 시각의 차이가 음수가 됐다. 화면에서 유효한 주차 상태를 `UNKNOWN`으로 판단해 보스 등장 화면이 반복해서 초기화될 수 있었다.

주차 상태의 유효성을 현재 시각으로 비교하도록 수정했다. 주기적인 만료 확인은 유지하며, 실제 주행·백그라운드·불명확한 상태에서는 기존처럼 게임을 중단한다. 피해량·보상·거리 계산 규칙은 바꾸지 않았다.

## 실제 앱 검사

- SDK 검사 2개 통과: 새 차량 상태가 들어오는 동안 전투 화면 유지와 체력 감소, Vehicle SDK 누적거리 조회와 백그라운드 해제. [결과](instrumentation-sdk-0.6.1.txt)
- 시연 앱 검사 2개 통과: 주행 중 차단과 주차 후 정산, 실제 처치·상자 개봉·장착·다음 보스. 기존 진행 상태를 저장하고 검사 후 복원했다. [결과](instrumentation-fixture-0.6.1.txt)
- release lint: 오류 0개, 경고 18개. [결과](lint-0.6.1.txt)
- 코어 게임 테스트 37개의 기존 통과 결과는 Gradle의 `UP-TO-DATE`로 재사용했다. 이번 수정에서 새로 실행한 테스트 수와 구분한다.
- SDK·fixture debug와 서명된 release APK를 빌드했다. 앱 버전은 0.6.1, 코드 7이다. 기존 서명을 유지했다.

## 차량 화면 촬영

공식 Pleos Connect 2.1 / API 34 에뮬레이터에서 실제 SDK 앱을 실행했다. Virtual Console의 가상 D 기어와 40km/h 입력에서 Pleos가 게임 화면을 차단하고, P로 주차한 후 게임으로 돌아오는 장면을 촬영했다. 주행 중 저장된 보스 체력·상자 수가 두 관측 사이에서 변하지 않음을 확인했다. [촬영 관측](vehicle-transition-0.6.1.json)

90초 영상은 차량 화면을 유지하면서 주행 중 중단, 주차 후 복귀, 거리 일격, 충전·대기 중 자동 사냥, 보상·강화·친구 교환을 설명한다. 10km는 가상 입력이며, 충전은 P 기어에서 앱을 사용하는 상황이다. 충전 상태 자동 감지 기능은 추가하지 않았다. [영상과 촬영 범위](../DEMO_VIDEO.md)
