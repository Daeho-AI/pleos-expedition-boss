# 원정 보스 90초 실행 시연

0.6.0의 실제 Pleos 앱 실행을 중심으로 구성했다. 영상은 1920×1440, 30fps, 90초이며 음성·음악·효과음 없이 큰 한국어 자막을 사용한다. 앱 세로 공간을 잘라내지 않고 전투·보상·조작을 읽을 수 있도록 4:3 프레임을 사용했다.

[영상 보기·다운로드](https://github.com/Daeho-AI/pleos-expedition-boss/releases/download/v0.6.0-preview.1/ExpeditionBoss-90s-Demo.mp4)

| 구간 | 실제 화면과 핵심 기능 |
|---|---|
| 0–6초 | Pleos 차량 화면과 원정 기지, 보스전 입장 |
| 6–14초 | 보스 등장 후 앱 전체가 전투장으로 전환 |
| 14–26초 | 장비를 반영한 픽셀 캐릭터·자동 공격·실제 체력 변화 |
| 26–33초 | 같은 보스를 처치한 뒤 승리·전리품 화면으로 이동 |
| 33–44초 | 실제 상자 개봉과 장비·코인·강화 재료 |
| 44–51초 | 다음 보스 등장과 전투 |
| 51–59초 | 가상 주행 차단·7분/10km 복귀 정산 |
| 59–67초 | 장비 미리보기·장착·강화 |
| 67–74초 | 게임 코인 상점 |
| 74–82초 | 실제 PC 서버의 친구·교환 화면 |
| 82–90초 | SDK 빌드의 차량 연결·누적거리·내비 진단 |

## 촬영 범위

- 녹화와 스크린샷은 실제 APK를 공식 Pleos 에뮬레이터에서 실행한 결과다. 게임 화면을 영상 편집기로 가짜로 만든 것이 아니다.
- 영상의 전투는 기존 15레벨 장비 상태와 체력이 가득 찬 첫 구역 보스로 준비했다. 피해율·드롭 규칙·상자 지급 코드는 수정하지 않았다. 기존 진행 데이터는 별도로 백업하고 촬영 뒤 복원한다.
- 사냥 중간 시간 축약, 기능별 장면 연결, 앱 영역 확대, 정지 화면과 설명 자막을 포함한다. 하나의 연속 주행 기록이 아니다.
- 7분·10km는 fixture 입력이다. 주행 중에는 전투가 중단되고, 주차 후 게임으로 돌아온 시점에 정산된다. 실제 SDK 수신과 구분한다.
- 실제 교환의 제안·수락 기능은 서버에 연결되어 있다. 화면에 표시한 계정은 시연용이다.
- 전투장과 승리·보상 화면은 실제 처치와 저장된 상자를 따라 바뀐다. UI가 보상이나 피해를 별도로 생성하지 않는다.
- 주행 속도·제한속도는 보상 조건이 아니며 순정 내비 지도 위에 게임을 덧그리지 않는다.
