## 촬영과 편집

2026년 11월 15일 **0.5.0** 앱을 공식 Pleos Connect Emulator 2.1.0에서 실행해 새로 촬영했다. 복귀 정산과 필살기 수치는 같은 버전의 초기 캐릭터 화면 테스트 결과다. 장착·강화·상자 개봉·상점 구매·교환 수락은 성장한 시연 캐릭터로 직접 조작했다. 장면별 레벨·재화는 하나의 연속 플레이가 아니다.

차량 전체 화면과 Pleos가 실제로 관리하는 분할 창을 촬영했다. 내비 화면 위에 게임을 합성하거나 오버레이 기능을 구현한 것처럼 표시하지 않았다. 분할 창 장면에서 에뮬레이터의 순정 내비 지도 타일은 표시되지 않은 상태다. 세부 기능은 실제 화면을 확대하고 정지 프레임을 유지해 읽을 시간을 확보했다. 앱 UI나 보상 수치를 새로 그리지는 않았다.

## 가상 입력과 SDK 수신

- 게임 시연은 fixture 빌드다. 7분 비움과 10km 이동은 가상 입력이다. 기본 보상은 최대 8시간, 거리 보너스는 한 번에 최대 30km이며 현재 보스의 남은 체력을 넘는 피해는 이월하지 않는다.
- 마지막 SDK 장면은 0.5.0의 `PLEOS_SDK` 빌드다. Vehicle SDK 2.3.2에서 공식 에뮬레이터의 누적거리 **0.000km**를 읽었다. [수신 상태](validation/sdk-visual-0.5.json)에 기록했다.
- Vehicle 누적거리는 복귀 필살기, AAOS 기어·화면 제한은 실행 허용 판단, NaviHelper는 안내 상태 진단에 사용한다. 목적지·경로는 바꾸지 않으며 위치·이동 경로를 수집하지 않는다.
- 친구 교환은 가상의 두 계정과 포함된 PC 서버로 촬영했다. 내 장비 밤빛 지팡이 영웅 +2와 상대 장비 별빛 창 희귀 +3을 확인하고 교환했다. 공개 운영 서버를 제공하는 장면이 아니다.
