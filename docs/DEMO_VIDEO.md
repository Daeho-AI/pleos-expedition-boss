# 원정 보스 차량 사용 시연

차량 화면 안에서 언제 멈추고, 언제 보상을 받고, 기다리는 시간을 어떻게 즐기는지 보여 주는 90초 영상이다. Pleos의 차량 화면과 조작 영역을 끝까지 유지하고, 장면마다 핵심 문장 하나를 크게 표시했다. 음성·음악·효과음은 없다.

[영상 다운로드](https://github.com/Daeho-AI/pleos-expedition-boss/releases/download/v0.6.1-preview.1/ExpeditionBoss-90s-Demo.mp4)

| 구간 | 보여 주는 기능 |
|---|---|
| 0–8초 | Pleos 차량 화면에서 시작하는 방치형 RPG |
| 8–20초 | D 기어·가상 40km/h에서 실제 SDK 앱의 게임 화면 차단 |
| 20–29초 | P 기어로 주차한 뒤 게임으로 복귀 |
| 29–41초 | 이동거리 10km에 따른 필살의 일격과 복귀 보상 |
| 41–52초 | 충전·대기 중 주차 상태에서 즐기는 자동 사냥 |
| 52–64초 | 보상 상자를 열어 장비·코인·강화 재료 확인 |
| 64–74초 | 장비 강화와 공격력 변화 |
| 74–82초 | 친구와 필요한 장비를 교환한 기록 |
| 82–90초 | 주행 중 중단과 주차 후 성장을 차량 화면에서 정리 |

## 촬영과 구현 범위

- 차량 전환은 SDK 0.6.1 앱을 공식 Pleos 에뮬레이터에서 새로 촬영했다. Virtual Console의 테스트 신호로 D·40km/h·P를 전환했다. 실차 영상은 아니다.
- 주행 중 두 시점의 저장 상태를 비교해 보스 체력과 상자 수가 변하지 않고 게임이 정지한 것을 확인했다. [관측 기록](validation/vehicle-transition-0.6.1.json)을 제공한다.
- 10km와 7분의 복귀 정산은 시연용 앱의 가상 입력이다. 영상에도 표시하며 실제 SDK 주행값으로 설명하지 않는다. 누적거리 실수신은 [SDK 연결 기록](validation/SDK_VALIDATION.md)을 참고한다.
- 충전 장면은 **P 기어에서 앱을 이용하는 상황**을 설명한다. 충전 연결·충전량·충전 완료를 자동 감지하는 기능은 현재 없다.
- 보상·장비·친구 장면은 기능과 화면이 같은 0.6.0 시연 녹화를 재사용했다. 친구 화면은 PC 서버에 연결한 가상 계정의 실제 교환 기록이다. 새 교환을 실행하는 영상은 아니다.
- 실제 앱 화면을 사용하며 장면 연결과 정지 화면을 포함한다. 하나의 연속 주행 기록이 아니다. 차량 화면을 가짜로 합성하거나 보상 수치를 영상에서 바꾸지 않았다.
- 영상 규격은 1920×1200, 30fps, H.264다. GitHub 주소는 다운로드 링크이므로 받은 MP4를 재생할 수 있다.
