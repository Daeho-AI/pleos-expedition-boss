# 원정 보스 90초 실행 시연

**[90초 MP4 보기·다운로드](https://github.com/Daeho-AI/pleos-expedition-boss/releases/download/v0.4.0-preview.1/ExpeditionBoss-90s-Demo.mp4)** · [한국어 자막](demo/ExpeditionBoss-90s-Demo.ko.srt) · [설치 안내](../README.md#설치하고-실행하기)

일상의 이동을 도착 후 성장으로 연결하는 방치형 RPG다. 주차·충전 대기 중 캐릭터의 자동 전투를 보고, 상자로 얻은 장비를 장착·강화하며 다음 보스를 준비한다. 주행 중 게임을 중단하고, 주차 후 돌아오면 시간 보상을 정산하며 확인한 이동거리로 필살의 일격을 적용한다.

2026년 11월 15일 **0.4.0 앱을 공식 Pleos Connect Emulator 2.1.0에서 실행해 녹화**했다. 캐릭터·보스·장비·보상은 앱에서 실제로 그리는 화면이다. 앱 영역의 확대·컷 편집과 짧은 큰 자막만 추가했으며, 읽어주는 음성이나 왼쪽 설명 패널은 없다. 음성·게임 효과음은 포함하지 않았다.

## 시연 입력과 실제 SDK 수신

- 게임 장면은 `boss-fixture-debug.apk`의 시연 캐릭터다. 시간과 **10km는 명시적인 가상 입력**이다. 주행 중단 전환만 0.5배속으로 보여 주며 화면에 표시한다.
- SDK 장면은 별도 `boss-pleos-debug.apk`의 `PLEOS_SDK` 모드다. Vehicle SDK 2.3.2의 `getCurrentDistanceDriven()`으로 공식 에뮬레이터가 제공한 **0.000km**를 읽는다. 10km 가상 입력을 실제 SDK 이동값으로 설명하지 않는다.
- 누적거리는 Pleos Vehicle, 기어·화면 제한은 AAOS, 내비 안내 상태 진단은 NaviHelper를 사용한다. 속도나 제한속도는 보상 조건이 아니다.
- 친구 기능은 포함된 PC 서버와 시연 계정을 사용한다. 현재 공개 운영 서버는 없으며, release 앱을 인터넷에서 사용하려면 HTTPS 서버 주소가 필요하다. 교환 기능 시험은 [검증 기록](validation/UPGRADE_0_4.md)에 있다.
- 녹화 사이 대기를 잘라냈으므로 장면 간 재화·상자·성장 수치가 연속적이지 않을 수 있다. 편집으로 능력치·보상·차량값을 만들어 넣지 않았다.
- 새 공격 모션은 기존 전투 결과를 표시한다. 연출이 별도 보상을 지급하지 않으며, 새 적 AI나 실시간 조작 전투를 추가한 버전은 아니다.

## 파일 정보

1920×1080, 30fps, 약 90초 H.264/AAC MP4다. 짧은 한국어 자막을 화면에 표시하며 SRT도 제공한다. [0.4.0 배포 페이지](https://github.com/Daeho-AI/pleos-expedition-boss/releases/tag/v0.4.0-preview.1)에서 영상과 설치 파일을 내려받을 수 있다. 크기·SHA-256·촬영 정보는 [시연 파일 정보](demo/video-manifest.json)에 기록했다.

앱 검증은 단위 37개·기기 14개이며, 범위와 재시도 내역은 [0.4 검증 기록](validation/UPGRADE_0_4.md)에 공개했다.
