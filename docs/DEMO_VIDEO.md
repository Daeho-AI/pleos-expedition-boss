# 원정 보스 시연

**[90초 영상 보기](https://daeho-ai.github.io/pleos-expedition-boss/)** · [MP4 내려받기](video/vehicle-demo.mp4)

원정 화면에서 시작해 출발과 주차, 이동거리 필살기, 주차·충전 대기 중 자동 사냥, 상자 개봉과 장비 성장, 친구 교환 내역을 보여 줍니다. 음성 없이 실제 앱 화면과 짧은 자막으로 구성했습니다.

| 구간 | 기능 |
|---|---|
| 0–8초 | 캐릭터와 원정 화면 |
| 8–20초 | 출발하면 게임 중단 |
| 20–29초 | 주차 후 게임 복귀 |
| 29–43초 | 이동거리 필살기와 복귀 보상 |
| 43–54초 | 주차·충전 대기 중 자동 사냥 |
| 54–65초 | 상자 개봉과 장비 획득 |
| 65–76초 | 장비 장착과 강화 |
| 76–84초 | 친구와 교환 내역 |
| 84–90초 | 원정 화면으로 복귀 |

모든 장면을 같은 소스의 앱으로 새로 촬영했습니다. 주행·주차 전환은 SDK 앱과 공식 Virtual Console의 가상 차량 신호를 사용했습니다. 10 km·7분 경과 및 캐릭터의 초기 장비·재화는 시연용 입력이며, 정산·개봉·장착·강화는 앱의 실제 기능입니다. 촬영 후 기존 게임 저장 상태를 복구했습니다.

친구 장면은 PC 서버의 교환 결과를 보여 줍니다. 충전 대기는 주차 상태의 이용 상황으로, 충전 연결을 자동 감지하는 기능은 아닙니다.
