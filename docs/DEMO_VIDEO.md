# 원정 보스 시연 영상

**[영상 재생 페이지](https://daeho-ai.github.io/pleos-expedition-boss/)**

## 차량 연동 시연

90초 동안 출발, 주행 중 게임 중단, 주차 후 필살기와 보상, 충전 대기 중 성장, 친구 교환을 보여 줍니다. 음성 없이 게임 화면과 짧은 한국어 자막으로 설명합니다.

[MP4 내려받기](video/vehicle-demo.mp4)

| 구간 | 기능 |
|---|---|
| 0–20초 | Pleos 차량 화면에서 출발하고 게임 중단 |
| 20–41초 | 주차 후 복귀, 이동거리 필살기와 보상 |
| 41–64초 | 주차·충전 대기 중 자동 사냥과 상자 개봉 |
| 64–82초 | 장비 강화와 친구 교환 내역 |
| 82–90초 | 차량 이용에 따른 게임 흐름 |

주행·주차 전환은 공식 Pleos 에뮬레이터의 SDK 앱으로 촬영했습니다. 10km 이동과 7분 경과는 시연용 가상 입력입니다. 친구 장면은 PC 서버에 저장된 교환 결과를 보여 줍니다. 충전 장면은 주차 중 이용 상황이며 충전 연결을 자동 감지하지는 않습니다.

## 게임 화면

원정 화면, 장비 선택과 강화, 보상, 상점, 친구, 도감을 약 1분 동안 보여 줍니다. 차량 연동 시연과 촬영 시점이 달라 화면 구성이 일부 다릅니다. 제출 APK의 화면은 이 영상에서 확인할 수 있습니다.
