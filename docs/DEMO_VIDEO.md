# 원정 보스 90초 실행 시연

**[MP4 영상 보기·다운로드](https://github.com/Daeho-AI/pleos-expedition-boss/releases/download/v0.3.0-preview.1/ExpeditionBoss-90s-Demo.mp4)** · [한국어 자막](demo/ExpeditionBoss-90s-Demo.ko.srt) · [앱 설치 안내](../README.md#설치하고-실행하기)

일상의 이동을 도착 후 성장으로 연결하는 방치형 RPG다. 주차·충전 대기 중 자동 사냥을 즐기고, 주행 중에는 게임 화면과 전투를 멈춘다. 주차 후 게임으로 돌아오면 시간 보상을 정산하고, 확인한 누적거리 차이로 필살의 일격을 적용한다. 보상 상자에서 얻은 장비를 강화하거나 친구와 교환하며 다음 원정을 준비한다.

2026년 11월 14일, **0.3.0 앱을 공식 Pleos Connect Emulator 2.1.0에서 실제 실행해 녹화**했다. 목업 화면이나 합성 플레이 화면은 사용하지 않았다. 앱 영역을 잘라 확대하고, 한국어 합성 해설·자막과 설명 패널을 편집으로 추가했다. 영상의 해설은 앱에서 나오는 소리가 아니다.

## 시연 입력과 실제 SDK 수신

- 게임 장면은 `boss-fixture-debug.apk`에서 촬영했다. **7분 비움·10km 복귀는 시연 버튼의 가상 입력**이다. 주행 중단과 복귀 전환을 읽기 쉽게 해당 구간만 0.5배속으로 편집하고 화면에 표시했다.
- SDK 장면은 `boss-pleos-debug.apk`의 `PLEOS_SDK` 모드다. Vehicle 2.3.2의 `getCurrentDistanceDriven()`으로 공식 에뮬레이터가 제공한 **0.000km**를 읽었다. 가상 10km 값을 실제 SDK 이동값으로 표시하지 않는다.
- 누적거리는 **Pleos Vehicle**, 기어·화면 제한은 **AAOS**, 내비 안내 상태 진단은 **NaviHelper**를 사용한다. 속도와 제한속도는 보상 조건이 아니다. [API별 사용과 시험 기록](validation/UPGRADE_0_3.md)을 참고한다.
- 친구 교환은 포함된 로컬 PC 서버와 두 시연 계정으로 진행했다. 수락 후 두 장비의 소유권이 바뀐 것을 서버에서도 확인했다. 인터넷에서 바로 이용할 공개 운영 서버는 없으며, release 앱에는 HTTPS 서버 주소가 필요하다.
- 녹화 구간 사이의 대기와 반복 조작을 잘라냈으므로 장면 간 코인·상자·성장 수치가 이어지지 않을 수 있다. 앱 데이터나 보상 수치를 영상 편집으로 바꾸지는 않았다.

## 파일 정보

영상은 1920×1080, H.264/AAC MP4, 약 90초다. 한국어 자막을 화면에 표시했으며 별도 SRT도 제공한다. MP4와 SRT는 [0.3.0 배포 페이지](https://github.com/Daeho-AI/pleos-expedition-boss/releases/tag/v0.3.0-preview.1)에 있다. 파일별 크기와 SHA-256은 [시연 파일 정보](demo/video-manifest.json)에 기록했다.

앱 코드와 APK는 이번 영상 제작으로 변경하지 않았다. 기존 단위 37개·기기 13개 시험 기록에 더해, 이번 촬영에서 실제 UI 조작과 교환 완료, SDK 조회를 다시 확인했다. 제출용 영상은 공모전 접수나 앱 마켓 승인 자체를 뜻하지 않는다.
