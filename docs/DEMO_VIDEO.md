주차 중 보스를 자동 사냥하고, 돌아오면 보상을 정산하며, 장비 수집·강화·친구 교환으로 성장하는 차량용 방치형 RPG다. 주행 중에는 게임 화면과 전투를 중단한다.

영상은 기능별로 **무엇을 하고, 어떤 결과가 생기는지** 보여 준다. 전투는 첫 6초에만 등장한다. 실제 앱의 보상 수치·강화 버튼·구매 확인창·교환 결과를 확대하고, 큰 설명을 함께 표시했다. 음성·음악·효과음은 없다.

## 촬영과 편집 범위

2026년 11월 15일 0.4.0 앱을 공식 Pleos Connect Emulator 2.1.0에서 실행한 녹화와 앱 테스트 화면을 사용했다. 상점 구매와 교환 수락은 이번 편집을 위해 다시 실행·촬영했다. 주행 차단·복귀 정산·필살기 결과는 실제 앱 캡처를 확대해 보여 준다. 가독성을 위해 정지 화면과 영상의 마지막 프레임 유지 편집을 사용했다. 앱 UI·보상·차량값을 새로 합성하지 않았다.

장면은 기능별 시연 예시이며 하나의 캐릭터를 연속 플레이한 영상이 아니다. 장면 사이 레벨·재화가 이어지지 않을 수 있다. 복귀 정산·거리 필살기 화면은 같은 초기 캐릭터의 결과이며, 장비 강화·상점·교환은 성장한 시연 캐릭터로 보여 준다.

## SDK 수신과 가상 입력

- 게임 기능은 `boss-fixture-debug.apk`로 시연했다. 7분과 10km는 시연 입력이며 화면에 명시한다. 복귀 보상은 최대 8시간, 거리 보너스는 한 번에 최대 30km까지 계산한다. 필살기 피해는 현재 보스의 남은 체력을 초과해 다음 보스로 넘어가지 않는다.
- SDK 장면은 `boss-pleos-debug.apk`의 `PLEOS_SDK` 모드다. Vehicle SDK 2.3.2의 `getCurrentDistanceDriven()`으로 공식 에뮬레이터가 제공한 **0.000km**를 읽은 화면이다. 이를 실제 도로 주행이나 10km SDK 입력 검증으로 설명하지 않는다.
- Vehicle SDK 누적거리는 복귀 시 추가 피해에 사용한다. AAOS 기어·화면 제한은 게임 실행 가능 여부를 결정한다. NaviHelper는 내비 연결·안내 상태를 진단한다. 현재 목적지·경로를 바꾸지 않으며, 위치·이동 경로는 수집하지 않는다.
- 교환은 포함된 로컬 PC 서버와 가상의 두 계정으로 실행했다. 상대가 제안한 잎사귀 외투(영웅 +2)와 밤빛 지팡이(영웅 +2) 교환을 앱에서 수락하고, 완료 및 교환함 반영을 확인했다. 공개 운영 서버는 없다. release 앱의 인터넷 이용에는 HTTPS 서버 주소가 필요하다.
